# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for a security problem. Report it
privately instead:

- via GitHub: **Security → Report a vulnerability** on this repository, or
- by email: **hellowerecratewise@gmail.com**.

Describe what you found and how to reproduce it. You'll get a reply as soon as
possible; Cratewise is a one-person project, so please allow a few days.

## Scope

- The Cratewise app code in this repository.
- Your Discogs personal access token is stored on your device with secure
  storage (Keychain on iOS, encrypted storage on Android) and is never sent
  anywhere except to the Discogs API.
- Problems in the Discogs API itself should be reported to Discogs.

## Supported versions

Only the latest release receives fixes.
