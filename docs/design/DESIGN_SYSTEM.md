# Design System

## Design direction

Cratewise should feel:

- Premium
- Clean
- Modern
- Fast
- Friendly
- Collector-focused

## Figma references

Use these Figma files as design references:

- Airbnb Design UI Kit 2025
- Airbnb Mobile App
- Airbnb UI Kit

Use them for inspiration around:

- Layout structure
- Mobile-first design patterns
- Card-based UI
- Search and filter patterns
- Onboarding screens
- Button styles
- Form styling
- Empty states
- Loading states
- Error states
- Spacing
- Typography hierarchy
- Responsive layout behavior

## Important branding rule

Do not copy Airbnb branding.

Do not use:

- Airbnb logos
- Airbnb name in the app branding
- Airbnb brand colors as the main identity
- Airbnb-specific illustrations
- Airbnb-specific copywriting
- Exact screen copies from Airbnb

## UI principles

Use:

- Large cover images
- Clear typography
- Rounded cards
- Modern buttons
- Simple forms
- Friendly onboarding screens
- Fast filters
- Compact list view
- Grid view for collection browsing
- Dark mode support
- Clean empty states
- Clear form validation states

## Accessibility

- Use readable contrast.
- Support dynamic text where possible.
- Use semantic labels for buttons.
- Keep touch targets large enough.
- Avoid using color alone to explain status.
