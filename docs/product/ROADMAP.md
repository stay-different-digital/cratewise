# Roadmap: Cratewise

## Platform scope

In scope:

- Android
- iPhone
- iPad

Out of scope:

- Windows desktop
- macOS desktop
- Web

## Phase 0: Product foundation

Goal:

- Finalize app name, MVP scope, users, design direction, and technical decisions.

Deliverables:

- Project brief
- Roadmap
- Architecture notes
- Security rules
- Design system notes

## Phase 1: Technical foundation

Goal:

- Create a stable Flutter foundation for Android, iPhone, and iPad.

Deliverables:

- Flutter project setup
- Android build
- iPhone build
- iPadOS build
- Routing
- Theme
- Local database setup
- Secure storage setup
- Basic settings screen

Done criteria:

- App starts on Android.
- App starts on iPhone.
- App starts on iPad.
- Navigation works.
- Theme works.
- Secure storage can save and remove a test value.

## Phase 2: Discogs MVP

Goal:

- Connect to Discogs with current token mode and search releases.

Deliverables:

- Token input
- Token validation
- Secure token storage
- Discogs API client
- Search screen
- Release detail screen

Done criteria:

- User can save a valid token.
- User can remove token.
- User can search releases.
- User can view release details.

## Phase 3: Collection MVP

Goal:

- Let users build and manage a local collection.

Deliverables:

- Add release to collection
- Collection list
- Collection detail
- Edit conditions, notes, tags, and storage location
- Remove collection item
- Offline collection view

## Phase 4: Wishlist and barcode

Goal:

- Add buying intent and faster lookup.

Deliverables:

- Wishlist
- Add to wishlist
- Barcode scanner for Android
- Barcode scanner for iPhone
- Barcode scanner for iPad

## Phase 5: Offline and sync

Goal:

- Make the app reliable without internet.

Deliverables:

- Local-first data
- Cached metadata
- Cached thumbnails where possible
- Sync status
- Retry failed actions

## Phase 6: Import and export

Goal:

- Give users control over their data.

Deliverables:

- CSV export
- CSV import
- Import preview
- Import validation

## Phase 7: Beta

Goal:

- Test with real users.

Deliverables:

- Android beta build
- iPhone beta build
- iPad beta build
- QA checklist
- Feedback process

## Phase 8: Version 1.0

Goal:

- Release a stable app.

Deliverables:

- Final branding
- Privacy policy
- Documentation
- Stable Android build
- Stable iPhone build
- Stable iPad build


## Phase 9: Growth

Possible features:

- Statistics
- Advanced filters
- Discogs login flow
- Discogs collection import
- Duplicate detection
- DJ fields like BPM, key, energy, gig crate
