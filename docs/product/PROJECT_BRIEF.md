# Project Brief: Cratewise

## Goal

Create a modern Flutter alternative for managing a vinyl collection with Discogs data.

## Platforms

- Android
- Windows desktop

## Main users

- Vinyl collectors
- DJs
- Casual record buyers

## Main value

Cratewise should make it easier to:

- Search Discogs releases
- Find the correct pressing
- Add releases to a local collection
- Manage conditions, notes, tags, and storage location
- Create a wishlist
- Scan barcodes on Android
- Work offline
- Export and import CSV files

## MVP scope

The MVP includes:

- Flutter project setup
- Android support
- Windows support
- Discogs current token connection
- Discogs release search
- Release detail page
- Local collection
- Wishlist
- Barcode scan on Android
- Manual barcode entry on Windows
- Offline collection
- CSV export

## Out of scope for MVP

Do not build these in MVP:

- Marketplace buying
- Marketplace selling
- Payments
- Messaging
- Social features
- Public profiles
- AI recommendations

## Branding

Cratewise is an independent app.

Allowed wording:

- Connect your Discogs account
- Search Discogs
- Uses the Discogs API

Avoid wording that suggests official partnership.
