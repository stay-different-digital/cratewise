# VS Code Setup

## Required extensions

- GitHub Copilot
- GitHub Copilot Chat
- Dart
- Flutter

## Verify customizations

Run this command in VS Code:

```text
Chat: Open Customizations
```

Check:

- Agents
- Skills
- Prompts

## Recommended commands

Use these commands from the Command Palette:

- `Chat: Open Customizations`
- `Chat: New Custom Agent`
- `Chat: New Prompt File`
- `/skills`
- `/prompts`

## Recommended first commands in terminal

```bash
flutter doctor
flutter pub get
dart format .
flutter analyze
flutter test
```

## Notes

The default VS Code locations are used:

- `.github/agents`
- `.github/skills`
- `.github/prompts`
- `.github/copilot-instructions.md`

No custom location settings are needed.
